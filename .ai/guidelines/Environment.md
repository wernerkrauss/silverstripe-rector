# Development environment & troubleshooting (WSL2 / DDEV)

## Project language
- The project language is **English**: all code, comments, commit messages,
  documentation and guidelines must be written in English.

## Shell standard
- All commands must be run in Bash (WSL2/Ubuntu).
- PHP commands always via `ddev` (e.g. `ddev php`, `ddev composer`, `ddev phpunit`).
